ขอบเขต

หน้า Export แสดงเฉพาะจำนวนและความคืบหน้า ไม่แสดง JSON หรือ iframe ทั้งหมด ค่าหลัง /embed/ เป็นค่าที่ parse ได้ ยังไม่ใช่ Video ID ที่ยืนยันแล้ว

JSON เก็บต้นฉบับและทุก taxonomy ส่วน CSV เป็นสรุป ฟิลด์ที่ไม่อยู่ใน mapping จะมีเหตุผลใน excluded_meta_keys หากพบข้อมูลรับรองจะตัดฟิลด์หรือปฏิเสธรายการนั้นโดยไม่แก้ต้นฉบับ
